## 总体画布

- 使用纵向 Excalidraw 长画布，一段占一个精确 `W × H` 的完整区块；完整长图中相邻区块之间保留大块纯白留白，不用紧贴的分隔线代替留白。
- 每段默认采用三层纵向结构：上方为原生可编辑信息流程，中间为一张对应手绘插画，底部为一句文字表述句。
- 阅读方向以从左到右、从上到下为主；连线不穿过正文，不让插画承担文字说明。
- 制作前必须从阶段 A.5 读取 `统一成品尺寸：<宽> × <高>（<比例>）`，它是本轮每段区块和手机分段预览的唯一尺寸真源。
- 所有段落使用完全相同的宽、高和比例；不得默认采用 3:2、3:4、9:16，也不得沿用上一次任务的尺寸。
- 完整长图由这些等宽区块与段间留白纵向拼接；每个区块按已确认尺寸重新排版，而不是把旧版画面机械裁切或拉伸。
- 插画在下半部分自适应排布并保持自身比例，水平居中，保留少量稳定白边；主体、连线和结果图标不得被裁切。
- 原始插画文件的画幅只有在用户明确要求时才跟随成品尺寸；否则选择最适合下半部分插画区的画幅。

## 完整长图段间留白

`assets/layout-reference.png` 是段间呼吸感与主标题层级的视觉参照，只参考比例和密度，不复制其文字、插画内容或旧版构图。

设单段完整成品尺寸为 `W × H`，段数为 `N`：

1. **默认段间留白：** `S = round(0.26H)`；验收允许范围为 `0.24H–0.30H`。这段留白只出现在完整长图，不加入单段 PNG、手机预览或阶段 A.5 已确认的单段尺寸。
2. **完整长图高度：** `LongH = N × H + (N - 1) × S`。第 `i` 段的起始纵坐标为 `Yi = i × (H + S)`，其中首段 `i = 0`。
3. **留白必须为空：** 从上一段区块底部到下一段区块顶部之间保持纯白，不放段号、虚线、箭头、装饰、脚注或跨段连线。下一段的段号和标题从下一段自身的顶部安全区重新开始。
4. **内部虚线不等于段间隔：** 如需浅灰虚线，只用于单段内部的信息区／插画区分界；不得横跨段间纯白留白。
5. **版式锚点：** 为每段添加置于最底层、锁定的白色矩形边界，精确为 `W × H`，并写入：

   ```json
   {
     "customData": {
       "taoRole": "section-frame",
       "taoSection": 1,
       "taoStyleExempt": true,
       "reason": "layout boundary"
     }
   }
   ```

   边界矩形使用白色填充和白色描边、`opacity: 100`、`locked: true`。它只用于确定区块与验证间距，不形成可见边框。

用户在当前任务明确要求其他段间距时可覆盖默认值，但必须统一应用到整张长图，并在交付说明中记录覆盖后的 `S/H`。

## 主标题字号与宽度

每段口播的第一句／第一层判断作为主标题。主标题必须比副标题、卡片标题和正文显著更大，同时不能越出画布：

1. 使用 Excalifont（`fontFamily: 5`）、居中对齐和章节蓝 `#1e40af`。
2. 初始字号：`F0 = clamp(round(0.052W), 56, 96)`。例如 `W = 1536` 时从约 `80 px` 开始。
3. 最大实际文本宽度：`TitleMax = 0.86W`；标题中心与画布中心的偏差不超过 `0.03W`，左右安全边距各不小于约 `0.07W`。
4. 排版后必须读取 Excalifont 的实际文本边界，而不是按字符数猜测。若单行宽度超过 `TitleMax`，逐步缩小字号，但不得小于 `Fmin = clamp(round(0.036W), 44, 64)`。
5. 若到 `Fmin` 仍放不下，拆成最多两行、语义平衡的标题，并恢复尽可能大的字号；禁止压缩字符、横向拉伸、裁切或让文字越界。
6. 副标题字号建议为主标题的 `0.38–0.46`，正文和节点文字再低一级；主标题始终是每段最先被看到的文字。
7. 主标题元素写入：

   ```json
   {
     "customData": {
       "taoRole": "section-title",
       "taoSection": 1
     }
   }
   ```

标题验收以渲染后的手机预览为准：一眼可见、不挤边、不与段号重叠，也不因短标题而显得过小。

## 标题区与纵向节奏

`assets/layout-reference.png` 是标题区呼吸感、信息模块间距和整体纵向节奏的最新参考。只参考空间比例，不复制其中的文字或具体场景。

设单段成品尺寸为 `W × H`。除非用户明确覆盖，按以下顺序排布：

1. **段号：** 放在左上安全区，建议 `x = 0.068W–0.08W`、`y = 0.026H–0.044H`。段号只做导航，不与主标题争夺视觉中心。
2. **主标题：** 顶部建议位于 `0.04H–0.06H`，默认锚点约 `0.047H`，水平居中。短标题也不得贴顶；长标题按上一节的宽度规则缩放或拆成两行。
3. **主标题到副标题：** 主标题实际文本底边与副标题顶边之间保留 `0.018H–0.03H`，默认约 `0.021H`。副标题默认一至两行，字号为主标题的 `0.38–0.46`，宽度不超过 `0.82W`，水平居中。
4. **副标题到正文首模块：** 副标题实际底边之后必须保留 `0.044H–0.085H` 的纯白呼吸带，常规页优先取约 `0.055H–0.06H`，再进入第一个对比框、流程节点、时间线或结论卡。正文首模块通常位于约 `0.17H–0.24H`。
5. **信息模块之间：** 同一行并列卡片的水平净间距建议为 `0.035W–0.07W`；上下两个主要信息组之间建议保留 `0.025H–0.055H`。让箭头有独立路径，不让文字、边框和箭头端点互相贴近。
6. **卡片内边距：** 普通卡片左右内边距取 `0.035W–0.05W`，或卡片宽度的 `7%–12%`；密集多行卡片上下取 `0.018H–0.031H`，短句提示框上下可放大到 `0.036H–0.056H`。文字较长时优先加高卡片或换行，不缩窄字形。

以 `1536 × 2048` 为例：

- 段号约位于 `x=104–123 px`、`y=53–91 px`，默认约为 `x=112 px`、`y=72 px`。
- 主标题顶部约为 `82–123 px`，默认约为 `y=96 px`。
- 主标题与副标题之间约留 `37–61 px`，默认约为 `42 px`。
- 副标题与第一个信息模块之间约留 `90–174 px`，常规页默认约为 `120 px`。
- 第一个信息模块通常从约 `y=348–492 px` 开始，常规页优先从约 `y=384 px` 开始。
- 普通卡片默认可先取左右 `64 px`、上下 `52 px`；短句提示框把上下内边距放大到约 `72–88 px`。

文字间距规则：

- 所有文本保持 Excalifont 的自然字距并设置 `autoResize: true`；Excalidraw 不提供独立字距控制时，不得用汉字间插空格、压缩文本框、横向缩放或拆成单字元素模拟字距。`FDE` 等英文缩写与中文相邻时只保留正常的半角空格，不把这段间距摊到整行汉字。
- 主标题多行时使用 `lineHeight: 1.15–1.25`；副标题使用 `1.25–1.35`；正文使用 `1.25–1.4`，同一层级保持一致。
- 标题、副标题和正文首模块分别写入以下角色标记；`section-content-start` 只标记首个信息组中一个处于最上方的代表元素：

  ```json
  {
    "customData": {
      "taoRole": "section-subtitle",
      "taoSection": 1
    }
  }
  ```

  ```json
  {
    "customData": {
      "taoRole": "section-content-start",
      "taoSection": 1
    }
  }
  ```

验收时必须查看渲染图，而不只检查 JSON：标题区应明显独立，副标题下方看得到一段完整白色呼吸带；但信息流程区内部仍应连贯，不得把每个节点都拉成彼此孤立的岛。

## 默认单段版式比例

除非用户在当前任务明确覆盖，不论本轮确认的是哪一种像素尺寸，每段完整成品图都按高度 `H` 使用以下默认比例：

1. **信息流程区：约 `0–66%H`。** 前约 `18%–24%H` 用于标题区与副标题后的呼吸带，其后放置核心对比／流程、阶段线和必要的关键信息卡。视觉内容应覆盖约 `64%–67%H`，形成疏密有序而完整的信息组。
2. **插画与收束区：约 `66%–100%H`。** 这是“手绘画面约占 1/3”的完整区域，包含插画、必要留白和底部收束句，不再把收束句额外加到 1/3 之外。
3. **插画主体：约 `66%–94%H`。** 按原始比例等比缩放、水平居中，不裁切、不拉伸；根据插画自身长宽比微调边界，但不得侵占上方信息流程。
4. **底部文字：约 `94%–100%H`。** 只放一行居中的本段结论、判断或记忆句；保持与插画有清楚间距，不放进插画图片内部。

排版验收：

- 信息流程在视觉上约占整张画面的 2/3，插画与底部文字共同占下方约 1/3。
- 保持“信息流程 → 手绘插画 → 文字表述句”的阅读顺序，不互换层级。
- 标题区按上一节保留明确呼吸带；其余信息区通过调整节点高度、卡片尺寸和组间距消化空间。信息区与插画之间不得出现超过 `7%H` 的无意义连续空白带。
- 不能为了凑比例压扁插画、裁掉人物或把信息文字烘焙进图片；比例不合适时应重新排版。
- 以 `1536×2048` 为例：信息流程的视觉下边界约在 `y=1310–1370`；插画位于其后并在约 `y=1925` 前结束；底部一句话位于最后约 `80–120 px`。这是布局锚点，不是机械裁切线。
- 以 `1536×2048` 为例：完整长图默认在相邻两段之间加入约 `532 px` 的纯白留白；主标题初始约 `80 px`，实际宽度不超过约 `1321 px`。

## 信息图语义色

颜色服务于语义，避免随意彩虹化：

| 语义 | 浅色填充 | 深色线／字 |
|---|---|---|
| 流程、常规信息 | `#dbeafe` | `#1e40af` |
| AI、战略、系统 | `#ddd6fe` | `#6d28d9` |
| 问题、触发、压力 | `#fed7aa` | `#c2410c` |
| 决策、洞察、提醒 | `#fef3c7` | `#b45309` |
| 结果、成功、增长 | `#a7f3d0` | `#047857` |
| 风险、禁止、误区 | `#fee2e2` | `#dc2626` |

正文优先使用 `#334155`／`#64748b`，章节标题可用 `#1e40af`。

## Excalidraw 原生元素默认样式

以下设置来自用户确认的 Excalidraw 属性面板，是每次输出的默认真源。除非用户在当前任务明确指定其他样式，不得依赖库默认值或沿用上一份文件的属性。

| 面板选项 | Excalidraw JSON | 执行规则 |
|---|---|---|
| 填充：实心 | `fillStyle: "solid"` | 所有有色矩形、椭圆、菱形使用实心填充 |
| 描边宽度：中 | `strokeWidth: 2` | 可见形状与箭头统一 2 px |
| 边框样式：实线 | `strokeStyle: "solid"` | 默认实线；段落分隔线等语义性虚线可例外 |
| 线条风格：最手绘 | `roughness: 2` | 形状和箭头使用 cartoonist／最高粗糙度 |
| 边角：圆角 | 矩形 `roundness: { "type": 3 }` | 矩形使用 adaptive radius；椭圆、菱形保持适用的原生形态 |
| 箭头类型：曲线 | 箭头 `roundness: { "type": 2 }`、`elbowed: false` | 使用 proportional radius 的曲线箭头，不默认使用直角肘形箭头 |
| 字体：Excalifont | `fontFamily: 5` | **所有 `text` 元素硬性使用**；中文由 Excalidraw 的手绘中文回退字体自动显示 |
| 文本对齐：居中 | `textAlign: "center"` | 标题、节点、说明默认居中；仅长清单为可读性允许左对齐 |
| 端点 | `startArrowhead: null`、`endArrowhead: "arrow"` | 流程箭头默认只在末端显示箭头 |
| 透明度 | `opacity: 100` | 所有元素必须为 100 |

字体大小按信息层级和已确认画布尺寸调整，不强制所有文字使用同一档；但字体家族始终保持 `fontFamily: 5`。背景承托矩形、图片元素和语义性虚线可豁免不适用的形状样式，豁免元素须在 `customData` 标明 `{ "taoStyleExempt": true, "reason": "..." }`，但不得豁免 Excalifont 和 100% 透明度规则。

构建元素时显式写入这些字段，不假设 Excalidraw 打开文件后会自动替换。完成后运行：

```bash
node "<TAO_SKILL_DIR>/scripts/validate-excalidraw-defaults.mjs" <成品.excalidraw>
```

其中 `TAO_SKILL_DIR` 指当前 `SKILL.md` 所在目录，不能按工作区当前目录猜测脚本位置。

## 锁定插画风格

使用 `assets/style-anchor.png` 只作为媒介和稚拙程度的参考。保持以下特点：

- 纯白背景，无边框、阴影、渐变和纸张底纹。
- 黑色或深海军蓝细签字笔线稿；线条略有抖动、重描、粗细和压力不均，接头不完全规整。
- 透视和人物比例可略显笨拙；五官简化，手脚允许小幅不完美，但仍是成年人绘制的知识插画，不是幼儿涂鸦。
- 彩色铅笔质感明显：可见排线、填色不均、少量露白和轻微越界。
- 仅少量使用钴蓝、柔紫、薄荷绿、橙色、浅黄与米灰。
- 构图清楚、人物有生活感，避免精致商业矢量感、光滑统一轮廓、动漫 Q 版、3D、写实与浓重阴影。
- 插画内部不得出现任何可读文字、字母、数字、标签、Logo 或水印；需要表达数据时使用无字符图形。

## 连续角色

如口播主体需要“老板”角色，默认保持同一形象贯穿各段：约 40 岁中国男性，略方脸，短而稍乱的黑发，蓝色西装外套、白衬衫、米色长裤、白色运动鞋。可改变姿势、表情和手中道具，不改变基本辨识特征。

## 单张插画提示词骨架

生成时先写本段独有的场景和视觉逻辑，再附加统一风格限制：

> 【按已确认的成品尺寸与下半部分插画区选择画幅；如用户要求原始插画同尺寸，则严格使用该尺寸】教育型知识插画，纯白背景，保留充足留白。场景为【本段人物、动作、道具、左右关系与视觉隐喻】。保持同一位老板角色。以深海军蓝细签字笔绘制略微抖动、重描、压力不均和接头不完美的线条；以钴蓝、柔紫、薄荷绿、橙、浅黄、米灰彩铅做不均匀排线，保留少量露白和轻微越界。整体像成年人亲手画出的略稚拙知识插画，清楚、有人情味。不要可读文字、字母、数字、Logo、水印、边框、渐变、写实阴影、光滑矢量、动漫 Q 版、3D 或照片感。

不得只写抽象主题；必须明确人物在做什么、对象如何排列、观众应一眼读出什么因果或对比。
